# examples/

A complete worked engagement, filled in with **synthetic data**, so you can see what the team
produces at every stage. Read it alongside [`../QUICKSTART.md`](../QUICKSTART.md).

| Folder | Engagement | Shows |
|---|---|---|
| `northwind-ia-procurement/` | Internal audit of procurement & supplier-payment controls at a fictional UK building society | All five gates end to end, including a mandatory EQCR (heightened risk), three findings, and the full `gate-log.jsonl` audit trail |

> Everything here is invented. Northwind Building Society does not exist; the people, numbers, and
> findings are fabricated for illustration. Real engagement files live in `engagements/`, which is
> gitignored because it is client-confidential.

## How to read the worked example

Follow the file order in `ENGAGEMENT.md`:
`acceptance-memo` → `engagement-plan` → `racm` → `findings-register` → `review-notes` →
`eqr-challenge-log` → `report` → `signoff-pack` → `close-memo`, with `gate-log.jsonl` as the
spine that records each human gate decision.
