# engagements/

Per-engagement working folders live here, one per engagement reference, created by
`tools/new-engagement.sh`. Each holds the workpapers, evidence, findings register, review
notes, EQR challenge log, sign-off pack, and the `gate-log.jsonl` audit trail.

**These are client-confidential and are gitignored.** They must not be committed to the public
template repo. Store real engagement files in an access-controlled location per your firm's
retention and confidentiality policy.

This README and `.gitkeep` are the only tracked files in this folder.
